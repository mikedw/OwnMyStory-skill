# Output Artifact Formats

Templates for exporting skill outputs as markdown files.

---

```markdown
[strategic_motivation text]

## 🏛 Leadership Pillar
[leadership_pillar text]

## ⭐ Value Proposition
> "[value_proposition text]"

---

### Discovery Conversation

**Q:** [question 1]
**A:** [response 1]

**Q:** [question 2]
**A:** [response 2]

**Q:** [question 3]
**A:** [response 3]
```
